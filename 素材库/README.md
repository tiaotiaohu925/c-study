## 目录

- `00_资源索引.md`：SQL、Excel、BI、Python、统计、A/B 测试和业务分析资源。
- `01_数据集与项目素材.md`：适合做作品集的公开数据和项目方向。
- `02_每周资料清单.md`：把资源映射到具体周次和交付物，先覆盖前 12 周，后续持续补充。

## 使用方式

1. 每周只打开本周资料，不要同时收藏所有网站。
2. 先看最少必要内容，然后立即做练习或项目。
3. 每周至少产出一个文件：SQL 脚本、Notebook、图表、仪表盘、报告或面试题答案。
4. 遇到登录、付费或地区限制时，换用同目录下的免费替代资源。
5. 每次使用资源后记录：是否有效、难度、是否值得继续投入。

## 资料状态说明

- 免费：当前可直接访问，不需要付费。
- 免费+注册：需要注册账号，核心功能通常可免费使用。
- 免费+付费：有免费内容，也有付费进阶内容。
- 参考：适合查询和查漏补缺，不作为主课程。
- 付费：需要购买或订阅，只作为可选补充。

## 每周维护约定

以后每周复盘时同时更新：

- 下周需要使用的课程、题库和数据集链接。
- 一个业务案例或行业报告。
- 一个可直接练习的项目任务。
- 一个 SQL/统计/业务面试题。
