## 六、选择规则

- SQL 主线：SQLBolt + HackerRank；面试阶段切换到 DataLemur/StrataScratch。
- Excel/BI 主线：Microsoft 培训 + ExcelJet；第 15 周后选 Power BI 或 Tableau 其中之一。
- Python 主线：pandas 官方文档 + Kaggle Learn，项目统一用 Jupyter Notebook。
- 统计主线：Khan Academy + Seeing Theory；A/B 测试用 Udacity 课程。
- 业务主线：AARRR + 产品指标文章 + 目标行业报告。
- 求职主线：牛客 + 上海就业服务网 + BOSS/前程/智联；后续会基于真实 JD 做关键词分析。
