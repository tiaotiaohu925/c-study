## 每周固定节奏

- 每天：20–30 分钟 SQL 维护练习。
- 周一、周三、周五：当前主技能学习和练习。
- 周二、周四：项目或数据处理任务。
- 周六：项目推进。
- 周日：复盘、更新周记录、整理作品集。

每周必须新增一份 `weekly/YYYY-Www.md`，并至少留下一个可见交付物。

## 提交规则

- 每周至少一次提交，提交信息格式：`week 01: SQL 基础与 Excel 仪表盘`
- 不提交账号密码、密钥、个人隐私数据或未获授权的企业数据。
- 大型原始数据不直接进入仓库，放入 `data/raw/`，并按目录说明处理。
- 项目完成后在 `projects/` 下保留 README、SQL、Notebook、图表和业务报告。
