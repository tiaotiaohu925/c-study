## 第 1 课：SQL 的基本结构

数据分析师最常用的查询结构：

```sql
SELECT 列名
FROM 表名
WHERE 筛选条件
ORDER BY 排序列
LIMIT 返回行数;
```

核心概念：

- 表是二维数据，每一行是一条记录，每一列是一个字段。
- `SELECT` 决定显示哪些列。
- `FROM` 决定从哪张表取数据。
- `WHERE` 决定筛选哪些行。
- `ORDER BY` 决定排序方式，默认升序，`DESC` 表示降序。
- `LIMIT` 决定最多返回多少行。

### SQL 语法重点

1. `SELECT * FROM orders;` 是查询所有字段的正确写法，不是 `SELECT ALL`。
2. SQL 中的文本值要用单引号，例如 `city = '上海'`、`status = 'paid'`。
3. 列名要准确，`amount` 不要写成 `amour`，`status` 不要写成 `staus`。
4. `ORDER BY amount DESC` 才是按金额降序；`age` 不在表中。
5. 聚合函数不能直接放在 `WHERE` 中，例如 `WHERE amount = MAX(amount)` 不合法。
6. 查询金额最高的一条：`SELECT * FROM orders ORDER BY amount DESC LIMIT 1;`
7. 统计数量必须写完整：`SELECT city, COUNT(*) AS num FROM orders GROUP BY city;`
8. 求和要写 `SUM(amount)`，不能写 `SUM(*)`。
9. `WHERE` 在分组前筛选行；`HAVING` 在分组后筛选结果。
10. 每两个字段之间要有逗号，例如 `SELECT city, COUNT(*) FROM ...`。

### 正确参考答案

```sql
-- 1
SELECT * FROM orders;

-- 2
SELECT * FROM orders WHERE city = '上海';

-- 3
SELECT * FROM orders WHERE amount > 100 AND status = 'paid';

-- 4
SELECT * FROM orders ORDER BY amount DESC;

-- 5
SELECT * FROM orders ORDER BY amount DESC LIMIT 1;

-- 6
SELECT city, COUNT(*) AS num
FROM orders
GROUP BY city;

-- 7
SELECT SUM(amount) AS total
FROM orders
WHERE status = 'paid';

-- 8
SELECT city, SUM(amount) AS total
FROM orders
WHERE status = 'paid'
GROUP BY city;

-- 9
SELECT city, COUNT(*) AS num
FROM orders
GROUP BY city
HAVING COUNT(*) > 1;

-- 10
SELECT customer, amount
FROM orders
WHERE status = 'refunded';
```

### Excel 纠正

- VLOOKUP 用于查找匹配，不用于分组求和。
- 每个城市的订单金额总和：插入透视表，行放 `city`，值放 `amount`，汇总方式选求和。
- `paid` 订单总金额：`=SUMIF(F2:F7, "paid", D2:D7)`，假设状态在 F 列、金额在 D 列。
- 找金额最高 3 条：对 `amount` 降序排序，或者使用 `LARGE` 函数。

### Python / pandas 纠正

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": [1, 2, 3, 4, 5, 6],
    "customer": ["张三", "李四", "王五", "赵六", "孙七", "周八"],
    "city": ["上海", "北京", "上海", "上海", "深圳", "北京"],
    "amount": [120, 80, 200, 150, 90, 300],
    "status": ["paid", "paid", "refunded", "paid", "paid", "paid"],
})

paid_orders = orders[orders["status"] == "paid"]
total = paid_orders["amount"].sum()

print(paid_orders)
print("paid total:", total)
```

核心步骤：

1. `orders["status"] == "paid"`：生成 True/False 筛选条件。
2. `orders[条件]`：筛选出符合条件的行。
3. `["amount"]`：取出金额列。
4. `.sum()`：求和。
