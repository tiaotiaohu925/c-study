## 第 1 课：变量和数据类型

```python
name = "郭昊"          # 字符串 str
age = 21               # 整数 int
score = 88.5           # 小数 float
is_paid = True         # 布尔值 bool
```

用 `print()` 输出：

```python
print(name)
print(age)
```

## 第 2 课：列表和字典

```python
cities = ["上海", "北京", "深圳"]
amounts = [120, 80, 200]

order = {
    "customer": "张三",
    "city": "上海",
    "amount": 120,
    "status": "paid",
}
```

- 列表用 `[]`，按顺序保存多个值。
- 字典用 `{}`，用键值对保存一条记录。
- 访问字典字段：`order["amount"]`。

## 第 3 课：循环

```python
for amount in amounts:
    print(amount)
```

带判断的循环：

```python
for amount in amounts:
    if amount > 100:
        print(amount)
```

## 第 5 课：pandas 最小用法

```python
import pandas as pd

orders = pd.DataFrame({
    "customer": ["张三", "李四", "王五"],
    "city": ["上海", "北京", "上海"],
    "amount": [120, 80, 200],
    "status": ["paid", "paid", "refunded"],
})

paid_orders = orders[orders["status"] == "paid"]
paid_total = paid_orders["amount"].sum()

print(paid_orders)
print(paid_total)
```
